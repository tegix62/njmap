# 08. Art (as built: placeholders drawn in code)

Everything on screen is generated by code (D59, D196); nothing is an image file, so any of it can be replaced by the user's own work later without touching the game.

| Piece | Where | What it is |
|---|---|---|
| Captain portraits | `js/goblin/ui/portrait.js` | 3 heads x 3 hats x 3 weapons chosen from the captain's id (the same captain always looks the same), a skin colour by kind of clan, **5 injury layers** (scar, lost ear, limp, lost eye, burn: one for each injury in the content file) and **3 expressions** (steady, grim, shaken) that follow the captain's state and injuries |
| The messenger | `js/goblin/ui/messenger.js` | one small goblin face, **4 expressions** (cheerful, steady, nervous, frantic) |
| Dice | `portrait.js` | the six die-face glyphs, tumbling once for about half a second; reduced-motion users get no motion |
| Clan colours | `goblin.js` | goblins green, rats brown, toads blue, gnomes violet, dwarves ochre, with a grey fog |
| Convoys | `goblin.js` | a dot in the clan's colour with a white ring |

**D196's list for a first playable, against what exists:** grunt sprite per clan (no sprites: a grunt is a number on a township, D127); captain parts (3, 3, 3: built); injury layers (5: built); portrait expressions (3: built); the messenger with 3 expressions (4: built); dice (built); a fill colour per clan (built); icons for traits and states (not built: words stand in).

**What the user would draw** if they choose to: the captain parts, the messenger, a clan emblem. The portrait file is the only place that would change.

## Council's terrain picture (added 2026-11-15)

`data/goblin-terrain.png` is the real terrain of New Jersey, dithered: elevation from the Mapzen/AWS terrain tiles (open data, https://registry.opendata.aws/terrain-tiles/; their sources include USGS 3DEP), shaded from the north-west and ordered-dithered to 15 colours by `tools/goblin/build_terrain.py`. Council draws it under the township colours, which are a tint over it. It is data, not placeholder art: rebuild it with the script, do not edit it by hand.
