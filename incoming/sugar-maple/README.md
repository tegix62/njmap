# Sugar maple (*Acer saccharum*)

Drop pictures of this tree in this folder. Keep the original file names (they let me find each picture's author and licence for the credit). Has a traced leaf outline already; a drawing and more photos still help.

What helps most, in order:
1. **Botanist's line drawing** (black and white, public domain): [search Commons for the drawing](https://commons.wikimedia.org/w/index.php?search=Acer+saccharum+Britton&title=Special%3AMediaSearch&type=image). A plate from Michaux's *North American Sylva* is great too: [search](https://commons.wikimedia.org/w/index.php?search=Acer+saccharum+Sylva&title=Special%3AMediaSearch&type=image).
2. **One whole leaf on a plain background** (white paper, a table, pavement), stalk included: these become the accurate leaf outline.
3. **Bark**, **twig with buds**, **the whole tree**, **fruit or seeds**, **flowers**, **fall colour**: one or two of each.

More pictures: [all Commons images of Acer saccharum](https://commons.wikimedia.org/w/index.php?search=Acer+saccharum&title=Special%3AMediaSearch&type=image).
