# Pictures for Trees of New Jersey

One folder per tree. Open a tree's folder for what helps most and links to search for its pictures. Upload with **Add file → Upload files** while inside the folder.

- Keep the original file names, so each picture can be credited.
- Pictures from Wikimedia Commons are fine: most are public domain or Creative Commons, and the app will credit them.
- Your own phone photos are better added in the app (a tree's page, *Add your own photo*): this repository is public, and phone photos often carry the place they were taken.
