# Eastern hemlock (*Tsuga canadensis*)

Drop pictures of this tree in this folder. Keep the original file names (they let me find each picture's author and licence for the credit). Needles or scales: a drawing and a few clear close-ups help most.

What helps most, in order:
1. **Botanist's line drawing** (black and white, public domain): [the 1913 drawing on Commons](https://commons.wikimedia.org/wiki/File:Tsuga_canadensis_drawing.png). A plate from Michaux's *North American Sylva* is great too: [search](https://commons.wikimedia.org/w/index.php?search=Tsuga+canadensis+Sylva&title=Special%3AMediaSearch&type=image).
2. **One whole leaf on a plain background** (white paper, a table, pavement), stalk included: these become the accurate leaf outline.
3. **Bark**, **twig with buds**, **the whole tree**, **fruit or seeds**, **flowers**, **fall colour**: one or two of each.

More pictures: [all Commons images of Tsuga canadensis](https://commons.wikimedia.org/w/index.php?search=Tsuga+canadensis&title=Special%3AMediaSearch&type=image).
