# Black walnut (*Juglans nigra*)

Drop pictures of this tree in this folder. Keep the original file names (they let me find each picture's author and licence for the credit). **High priority**: no accurate leaf outline yet.

What helps most, in order:
1. **Botanist's line drawing** (black and white, public domain): [search Commons for the drawing](https://commons.wikimedia.org/w/index.php?search=Juglans+nigra+Britton&title=Special%3AMediaSearch&type=image). A plate from Michaux's *North American Sylva* is great too: [search](https://commons.wikimedia.org/w/index.php?search=Juglans+nigra+Sylva&title=Special%3AMediaSearch&type=image).
2. **One whole leaf on a plain background** (white paper, a table, pavement), stalk included: these become the accurate leaf outline.
3. **Bark**, **twig with buds**, **the whole tree**, **fruit or seeds**, **flowers**, **fall colour**: one or two of each.

More pictures: [all Commons images of Juglans nigra](https://commons.wikimedia.org/w/index.php?search=Juglans+nigra&title=Special%3AMediaSearch&type=image).
